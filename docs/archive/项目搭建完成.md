## 🚀 启动步骤

### 1. 后端启动

```bash
# 进入后端目录
cd children-games-backend

# 安装依赖（已完成）
npm install

# 配置数据库
# 编辑 .env 文件，填写你的 MySQL 配置
# DB_HOST=localhost
# DB_PORT=3306
# DB_NAME=children_games
# DB_USER=root
# DB_PASSWORD=你的密码

# 创建数据库
mysql -u root -p
CREATE DATABASE children_games CHARACTER SET utf8mb4;
exit;

# 导入初始数据（可选）
mysql -u root -p children_games < database/init.sql

# 启动后端服务
npm run dev
```

后端将运行在 http://localhost:3000

### 2. 前端启动

```bash
# 进入前端目录
cd children-games-frontend

# 安装依赖（已完成）
npm install

# 启动开发服务器
npm run dev
```

前端将运行在 http://localhost:8080

### 3. 访问游戏

打开浏览器访问 http://localhost:8080

系统会自动创建测试用户并登录。

## 🎮 游戏特色

### 记忆翻牌 🧠
- 翻转卡片，配对相同图案
- 关卡递进：2对 → 8对
- 时间限制：60秒 → 30秒

### 接水果 🍎
- 移动篮子接住掉落的水果

### 拼图游戏 🧩
- 滑动拼图块完成图片

### 打气球 🎈

- 击破上升的气球
- 特殊气球：金色(25分)、彩虹(50分+全屏清除)

### 坦克大战 🚀
- 控制坦克左右移动
- 自动射击敌人

- 生命系统

## 📊 成长系统

### 星星系统
- 每关根据表现获得 1-3 颗星
- 星星累积解锁新关卡
- 总星星数决定玩家等级

### 玩家等级
- 每 100 颗星升一级
- 等级显示在个人中心

### 每日任务
- 每天完成 3 个游戏
- 获得额外 10 颗星奖励

### 成就系统
- 预设成就徽章
- 达成条件自动解锁

## 🐛 常见问题

### Q: 后端启动失败？
A: 检查 MySQL 是否运行，.env 配置是否正确

### Q: 前端无法连接后端？
A: 确保后端运行在 3000 端口，检查 vite.config.ts 的 proxy 配置

### Q: 游戏卡顿？
A: 降低 Canvas 分辨率，减少动画帧率
