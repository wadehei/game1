## 3. STRIDE 威胁分析

### 3.1 Spoofing（伪装）

> 攻击者冒充合法用户或系统组件

| 威胁ID | 威胁描述 | 攻击场景 | 现有控制 | 风险等级 | 缓解措施 |
|--------|---------|---------|---------|---------|---------|
| SP-01 | JWT Token 伪造 | 攻击者伪造或篡改 JWT 冒充用户 | HS256 签名验证 | 🟡 中 | 使用 RS256 非对称签名；添加 jti 防重放 |
| SP-02 | 微信 OAuth 回调伪造 | 伪造微信回调请求，注入虚假 openid | state 参数校验 | 🟢 低 | 确保 state 随机且一次性；验证 signature |
| SP-03 | 管理员身份冒用 | 通过弱密码或泄露凭证登录后台 | 密码哈希 + 限流 | 🟡 中 | 强制强密码策略；启用 2FA |
| SP-04 | WebSocket 连接冒充 | 未认证用户发送 WS 消息 | 连接时 JWT 验证 | 🟢 低 | 定期 re-auth；消息签名 |
| SP-05 | JWT 长期令牌无撤销 | 365天家庭令牌被盗后无法作废 | ✅ 15min access token（黑名单可撤销）+ 30天 refresh token（服务端存储，logout/logout-all 可撤销）；⚠️ 迁移期：存量无 type 字段的旧令牌兼容但不可撤销，待自然过期 | 🟡 中（迁移期） | refresh rotation 与重用检测待排期 |
| SP-06 | 可预测 OpenID | `Date.now()` 生成的 openid 可被猜测碰撞 | 无 | 🟠 高 | 使用 `crypto.randomUUID()` |

### 3.2 Tampering（篡改）

> 攻击者未经授权修改数据或代码

| 威胁ID | 威胁描述 | 攻击场景 | 现有控制 | 风险等级 | 缓解措施 |
|--------|---------|---------|---------|---------|---------|
| TM-01 | 客户端游戏状态篡改 | 修改内存中的金币数量/牌组 | 服务端权威状态 | 🟢 低 | 所有状态变更服务端计算 |
| TM-02 | API 请求参数篡改 | 修改请求中的金额/用户ID | Joi schema 校验 | 🟡 中 | 严格白名单校验；服务端查权限 |
| TM-03 | WebSocket 消息注入 | 发送伪造的游戏操作消息 | 消息类型白名单 | 🟡 中 | 校验消息来源房间；序列号防重放 |
| TM-04 | 数据库直接篡改 | SQL 注入修改数据 | 参数化查询 | 🟢 低 | 持续使用 ORM；禁止字符串拼接 |
| TM-05 | 头像上传恶意文件 | 上传含 XSS 的图片 | MIME 白名单 + 大小限制 | 🟡 中 | 图片重编码（去除 EXIF）；CDN 隔离 |
| TM-06 | 可预测随机数 | `Math.random()` 生成的牌序可被预测 | 无 | 🔴 严重 | 改用 `crypto.randomBytes()` 洗牌 |
| TM-07 | 调试钩子残留 | `BLACKJACK_RIGGED` 环境变量可使庄家必赢 | 无 | 🟠 高 | 生产环境移除或编译时排除 |

### 3.3 Repudiation（抵赖）

> 用户否认执行的操作，缺乏审计追踪

| 威胁ID | 威胁描述 | 攻击场景 | 现有控制 | 风险等级 | 缓解措施 |
|--------|---------|---------|---------|---------|---------|
| RP-01 | 游戏对局争议 | 用户否认下注/出牌操作 | 对局记录持久化 | 🟢 低 | 关键操作写审计日志；支持 replay |
| RP-02 | 金币交易争议 | 用户否认转账/下注 | 交易流水记录 | 🟡 中 | 每笔交易有唯一 ID + 签名；对账机制 |
| RP-03 | 管理员操作追溯 | 管理员修改数据后否认 | ✅ 审计日志中间件（19处覆盖） | 🟢 低 | ~~已实现~~ |
| RP-04 | 登录否认 | 用户否认某次登录行为 | 无登录日志 | 🟡 中 | 记录登录 IP/时间/方式 |

### 3.4 Information Disclosure（信息泄露）

> 敏感数据暴露给未授权方

| 威胁ID | 威胁描述 | 攻击场景 | 现有控制 | 风险等级 | 缓解措施 |
|--------|---------|---------|---------|---------|---------|
| ID-01 | JWT 明文传输 | 中间人窃取 token | HTTPS 强制 | 🟢 低 | HSTS；证书固定（可选） |
| ID-02 | 错误信息泄露 | 堆栈信息暴露内部实现 | 统一错误响应 | 🟢 低 | 生产环境隐藏 stack trace |
| ID-03 | 日志泄露 PII | 日志记录敏感信息 | logger 配置 | 🟡 中 | 脱敏处理（openid/手机号） |
| ID-04 | 数据库凭证泄露 | .env 文件泄露 | 环境变量 | 🟡 中 | 文件权限 600；不提交到 git |
| ID-05 | 用户数据越权访问 | 用户A查询用户B数据 | 用户 ID 校验 | 🟡 中 | 基于 session 查用户；禁传 userId |
| ID-06 | Redis 缓存泄露 | 未授权访问 Redis | 密码认证 | 🟢 低 | 限制 bind 地址；禁用危险命令 |
| ID-07 | 儿童信息泄露 | 家庭成员信息暴露 | API 权限控制 | 🔴 高 | 严格家长权限校验；最小化数据暴露 |
| ID-08 | 聊天内容无过滤 | 儿童平台存在不当内容风险 | 仅 200 字符限制 | 🔴 严重 | 敏感词过滤 + 举报机制 + 家长审核 |

### 3.5 Denial of Service（拒绝服务）

> 使系统不可用或性能严重下降

| 威胁ID | 威胁描述 | 攻击场景 | 现有控制 | 风险等级 | 缓解措施 |
|--------|---------|---------|---------|---------|---------|
| DS-01 | API 请求洪水 | 大量请求耗尽服务器资源 | express-rate-limit | 🟡 中 | 调整限流阈值；分布式限流（Redis） |
| DS-02 | WebSocket 连接洪水 | 大量假连接占满资源 | 连接数限制 | 🟡 中 | 单 IP 连接上限；快速踢出空闲连接 |
| DS-03 | 慢查询攻击 | 触发复杂查询拖垮 DB | 查询超时 | 🟡 中 | 慢查询告警；读写分离 |
| DS-04 | 大文件上传 DoS | 上传超大文件耗尽磁盘 | 文件大小限制 | 🟢 低 | 5MB 上限；临时文件定期清理 |
| DS-05 | 房间资源耗尽 | 创建大量房间占满内存 | 房间数限制 | 🟡 中 | 全局房间上限；空闲房间自动清理 |
| DS-06 | 排行榜缓存穿透 | 缓存失效时大量 DB 查询 | 缓存预热 | 🟢 低 | 互斥锁重建；永不过期 + 主动刷新 |
| DS-07 | 头像上传磁盘耗尽 | 未认证接口可被滥用填满磁盘 | 20次/分钟限流 | 🟠 高 | 总磁盘配额监控 + 定期清理 + 认证要求 |

### 3.6 Elevation of Privilege（权限提升）

> 获取超出授权范围的权限

| 威胁ID | 威胁描述 | 攻击场景 | 现有控制 | 风险等级 | 缓解措施 |
|--------|---------|---------|---------|---------|---------|
| EP-01 | 普通用户访问管理 API | 调用 /api/admin/* 接口 | adminAuth 中间件 | 🟢 低 | 角色校验；白名单路由 |
| EP-02 | 家长访问其他家庭 | 查看/修改其他家庭数据 | familyId 校验 | 🟡 中 | 基于 token 查 familyId；禁传参 |
| EP-03 | 玩家操控游戏结果 | 客户端计算胜负 | 服务端权威 | 🟢 低 | 所有游戏逻辑服务端执行 |
| EP-04 | 测试接口泄露到生产 | /api/test/* 接口暴露 | ✅ 环境检查返回 403 | 🟡 中 | 生产环境不注册路由（条件导入） |
| EP-05 | WebSocket 越权操作 | 操作非自己房间的状态 | roomId 校验 | 🟡 中 | 校验用户是否在房间内 |
